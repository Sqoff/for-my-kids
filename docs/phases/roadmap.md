# [Phase Roadmap] 개발 단계 및 마일스톤 계획

> **테스트 방침**: 모든 Phase의 기능 검증은 **USB로 연결된 실제 안드로이드 폰 (Samsung Galaxy Z Flip 등)**에서 직접 실행하고 검증한다.

> ⚠️ **현재 구현 현실 (2026-09-27 기준)**: 현재 앱(Capacitor 프로토타입)에는 서버가 없다. 부부 간 알림·할 일·페널티 등 모든 "상대방 연동"은 **한 기기 안의 `STATE`로 엄마/아빠를 시뮬레이션**하는 방식이며, 두 폰 사이로 전달되지 않는다. 실기기 간 연동과 실제 앱 차단은 **디자인 완료 후 [🔒 최종 연동 단계](#-최종-연동-단계-디자인-완료-후-일괄-진행)에서 일괄 구현**한다 (ADR 32).

## 🔒 최종 연동 단계 (디자인 완료 후 일괄 진행)
> 사용자 결정 (2026-09-27, ADR 32): 화면·디자인 작업을 모두 마친 뒤, 실제 기기/서버 연동 작업을 마지막에 몰아서 진행한다. 화면과 기능이 확정된 뒤 데이터 구조를 한 번에 옮겨 재작업을 줄이기 위함.

1. **부부 계정 연결** — 소셜 로그인(카카오/구글) + **초대 코드 생성 → 배우자가 코드 입력 → 부부 방 연결** 방식 (`couples.inviteCode`, [api-data.md](../specs/api-data.md)). 현재 프로필 화면의 `BBOMA-7749` 코드는 고정 텍스트(복사 토스트만 동작).
2. **실시간 데이터 동기화** — 할 일·페널티권·퀘스트·알림 등 `STATE`를 Cloud Firestore로 이전, 두 폰 실시간 공유.
3. **원격 푸시 알림 (FCM)** — 응원하기, 대신 돕기, 페널티 공격/수정, 할 일 완료 등 부부 알림이 앱이 꺼져 있어도 상대방 폰에 도착.
4. **실제 앱 차단** — `UsageStatsManager`(사용 기록 접근 권한)로 딴짓 앱 실행 감지 + **접근성 서비스로 홈 화면 이동** + "육아 집중 중" 안내 알림. 오버레이(`SYSTEM_ALERT_WINDOW`)는 ADR 21에 따라 사용 금지. 플레이스토어 배포 시 접근성 사용 사유 심사 필요.
- [ ] **테스트**: USB 연결 실기기 2대(부부 폰)로 연결·동기화·푸시·차단 실동작 검증
